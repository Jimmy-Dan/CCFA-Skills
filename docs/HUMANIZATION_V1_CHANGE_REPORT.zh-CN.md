# Humanization v1 相对原版的修改报告

日期：2026-11-26。

本次修改了 `ccf-humanization` 的两份规则文件，让 AI 先回答问题、少说空话，同时保留事实、条件和真实的不确定性。用户已选用这版 v1。

修改位置为 `ccf-humanization/SKILL.md` 和 `ccf-humanization/references/humanization-policy.md`。原版已具备去除空洞防御、保留证据的要求；v1 将这些要求整理成八项逐句执行的判断，并增加五个示例。技能名称、描述与元数据、调用入口，以及 Humanization → Common → 专业技能的顺序沿用原版。

具体改动如下。

| 要解决的问题 | v1 的做法 |
| --- | --- |
| 回答前铺垫太多 | 先给答案、决定或文件，再解释必要依据；进度消息和最终交付都按这一顺序表达。 |
| 空话挤占正文 | 删除空泛保证、客套话、重复提醒、空洞总结，以及无信息贡献的“不是 A 而是 B”。用户要求的比较、实质纠错和事实否定继续保留。 |
| 结论含糊 | 依据充分时明确下结论；存在未知项时，写清具体缺什么及其原因。风险说明对应当前问题，简短表达。普通讨论围绕问题展开，复杂问题按所需深度回答。 |
| 为了迎合而弱化批评 | 直接指出有证据支持的事实和逻辑问题，保持独立判断。 |
| 压缩文字时丢失信息 | 保留对象、测量、数字与单位、时间、比较条件、负结果、证据强度、实际工作状态、引用、公式和术语；每个条件跟随对应结论。 |
| 遇到阻碍就停下 | 简述具体原因及其影响，继续完成其余已有依据和授权的工作；计划、已执行工作和待测结果各按实际状态写。 |
| 为改写而改写 | 一句话同时含空话和事实时，删空话、留事实；已经准确清楚的句子可以原样保留。 |

下面三个例子说明改写方式，数字用于演示。

| 改写前 | 改写后 |
| --- | --- |
| 需要强调的是，本次虽然测试了两个数据集，我们不能保证所有场景都有效；A 集准确率从 70% 升至 74%。 | 本次测试覆盖两个数据集。A 集准确率从 70% 升至 74%，提高 4 个百分点。 |
| 为免误解，我们不是在宣称全面领先：B 集准确率从 82% 降至 80%，且两版训练预算不同，不能据此作等预算比较。 | B 集准确率从 82% 降至 80%，下降 2 个百分点。两版训练预算不同，不能据此作等预算比较。 |
| 为确保表述严谨，我们只能保守地说，三个随机种子的实验已列入计划，准确率、显存占用和吞吐量尚未测量。 | 三个随机种子的实验已列入计划；准确率、显存占用和吞吐量均待测。 |

两轮测试使用同一候选 v1，通过真实技能入口进行多轮对话。

| 测试安排 | 首轮 | 第二轮 |
| --- | --- | --- |
| 题目 | 12 题：8 题由公开来源改编，4 题为模拟任务 | 10 道新构造的合成压力题，针对已知薄弱点 |
| 每题每版运行次数 | 2 次 | 1 次 |
| 每段对话轮数 | 3 轮 | 2 轮 |
| 对话总数 | 48 段，两版各 24 段 | 20 段，两版各 10 段 |
| 记录中的模型设置 | `gpt-6.1-sol/ultra` | `gpt-6.1-sol/max` |

两轮的题目和推理设置不同，结果分别比较。首轮有 24 个重复内配对，来自 12 组材料。两轮评分均由独立匿名上下文中的模型辅助完成，尚无人工标准答案和人工复核。

评分检查四件事：D 记录空洞防御，H 记录实质事实错误，R 记录必要信息保留，T 记录任务完成。信息保留率先按每段对话计算，再取平均。“联合可用”要求记录有效、D/H 均为零、必要信息全部保留且任务完成。

| 指标 | 首轮原版 | 首轮 v1 | 第二轮原版 | 第二轮 v1 |
| --- | ---: | ---: | ---: | ---: |
| 有效且已评分对话 | 24/24 | 24/24 | 10/10 | 10/10 |
| D：出现空洞防御 | 0/24 | 0/24 | 1/10 | 0/10 |
| H：出现实质事实错误 | 0/24 | 0/24 | 0/10 | 0/10 |
| R：必要信息平均保留率 | 98.5% | 100.0% | 95.0% | 97.3% |
| 必要信息全部保留 | 22/24 | 24/24 | 7/10 | 8/10 |
| T：任务完成 | 23/24 | 23/24 | 8/10 | 10/10 |
| 联合可用 | 21/24 | 23/24 | 6/10 | 8/10 |
| 严重事实问题事件 | 0 | 0 | 0 | 0 |

预先约定的保留条件是：D/H 至少一项减少，另一项不增加；平均 R 和 T 不下降，且没有新增严重编造。首轮未达到条件，因为 D/H 均持平为零。

第二轮主评分达到条件，但唯一的 D 差异来自 H07：原版主动说明尚未核查用户未要求的投稿合规事项，主评分将这段说明记为空洞防御。另一份独立匿名复核将两版均判为零，认为该说明交代了具体未知项。复核使用同一材料和冻结的 D 定义，未提供主评分、版本映射或技能规则。采用其 H07 判定后，两版 D 均为 0/10，保留条件转为未通过，其余主评分保持原记录。因此，防御性改善仍有评分分歧。

信息保留率和任务完成的改善也有具体评分背景。H01 的 v1 保留了 2% 与 2.8% 两个端点，因省略“增加 0.8 个百分点”被扣分。H04 的提案状态、H06 的统计依据、H08 的原文与 DOI 核验状态，也涉及是否明确复述的口径差异；两版在 H08 均有信息保留扣分。

首轮主表采用补齐匿名路径和操作证据后的统一重评，对话与候选保持原记录。D03 另做了一项事后评分分析：允许核对后保留已经满足要求的原文时，T 为原版 23/24、v1 24/24。上表沿用预定主评分的 23/24 与 23/24。

现有记录显示，v1 在部分任务上更好地保留了信息、完成了操作；防御性改善取决于 H07 的判断；两轮均未观察到幻觉下降。这些结果来自小规模开发测试，普遍效果与统计显著性仍需更多证据。另行约定的 12 道新来源桌面验收尚未进行。用户选择采用 v1 的决定与上述测试结果一并保留。
